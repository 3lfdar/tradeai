# استودیو ویدیو TradeAI Pro

ساخت ویدیوی اینستاگرام و یوتیوب با موشن‌گرافیک کدمحور.
یک سورس → دو خروجی (۹:۱۶ و ۱۶:۹)، با همان رنگ‌ها و فونت اپ اصلی.

## راه‌اندازی (یک‌بار)

```bash
cd video
npm install
```

ffmpeg هم لازم است. اگر نداری:

```bash
sudo apt-get install -y ffmpeg     # لینوکس
brew install ffmpeg                # مک
```

## ساخت یک ویدیو — سه قدم

### ۱. فوتیج را آماده کن

فایل‌های خام را با این اسکریپت نرمال کن و در `public/footage/` بگذار:

```bash
./scripts/prep-footage.sh raw/clip.mp4 public/footage/talking-head.mp4 --cut-silence
```

`--cut-silence` سکوت‌های ابتدا و انتها را می‌برد و صدا را روی سطح استاندارد پلتفرم‌ها می‌آورد.

**نکات ضبط:**
- چارت را جداگانه **اسکرین‌ریکورد** کن — با موبایل از مانیتور فیلم نگیر
- اگر افقی می‌گیری، خودت را کمی خارج از مرکز نگه دار و بعد در `content.ts` مقدار `focusX` را تنظیم کن تا در کراپ ۹:۱۶ درست بیفتی
- صدا را با میکروفون جدا ضبط کن

### ۲. محتوا را بنویس

فقط `src/content.ts` را عوض کن — همه‌ی متن‌ها، اعداد سیگنال، آمار و زیرنویس آنجاست.

زیرنویس آماده داری؟ SRT را تبدیل کن:

```bash
node scripts/srt-to-cues.mjs subs.srt > cues.txt
# محتوای cues.txt را در content.ts جایگزین کن
```

ریتم و طول سکانس‌ها در `src/Video.tsx` → `TIMELINE` تنظیم می‌شود (بر حسب ثانیه).

### ۳. پیش‌نمایش و رندر

```bash
npm run studio        # پیش‌نمایش زنده در مرورگر، با تایم‌لاین
./scripts/render.sh   # رندر هر دو خروجی
```

خروجی‌ها:
- `out/instagram-reels.mp4` — ۱۰۸۰×۱۹۲۰
- `out/youtube.mp4` — ۱۹۲۰×۱۰۸۰

فقط یکی را می‌خواهی؟ `./scripts/render.sh reels` یا `./scripts/render.sh youtube`

## سکانس‌ها

| سکانس | فایل | کارش |
|---|---|---|
| اینترو | `compositions/Intro.tsx` | لوگو + تیتر قلاب |
| تحلیل سیگنال | `compositions/SignalScene.tsx` | چارت کندلی انیمیشنی + خطوط ورود/حد ضرر/تارگت + کارت سیگنال |
| توک‌هد | `compositions/TalkingHead.tsx` | فوتیج خودت + زیرنویس فارسی + لوئر ثرد + واترمارک |
| معرفی اپ | `compositions/AppShowcase.tsx` | اسکرین‌ریکورد در موکاپ گوشی + لیست ویژگی‌ها |
| نتایج | `compositions/StatsScene.tsx` | کارت‌های آماری با اعداد کانت‌آپ |
| اوترو | `compositions/Outro.tsx` | کال‌تو‌اکشن + هندل |

سکانسی را نمی‌خواهی؟ در `src/Video.tsx` بلوک `<Sequence>` مربوطه را حذف کن یا در `TIMELINE` صفرش کن.

## چند ترفند

**چارت با دیتای واقعی:** به `SignalScene` پراپ `candles` بده — آرایه‌ای از `{o, h, l, c}`. اگر ندهی، از دیتای شبه‌واقعیِ قابل‌تکرار استفاده می‌کند.

**رنگ‌ها:** در `src/theme.ts` هستند و مستقیماً از `:root` فایل `index.html` اپ آمده‌اند. اپ را عوض کردی، اینجا هم عوض کن تا برند یکدست بماند.

**رندر سریع‌تر هنگام تست:** `npx remotion render Reels out/t.mp4 --frames=0-90`

**فونت:** وزیرمتن به‌صورت لوکال در `public/fonts/` است، پس رندر بدون اینترنت هم کار می‌کند.
